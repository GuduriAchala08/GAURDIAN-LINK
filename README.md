
# Guardian Link

## Overview
Guardian Link is a blockchain-based platform designed to securely share and manage sensitive data, ensuring privacy and transparency.

## Features
- **Parent dashboard**: Securely store data on a blockchain network.
- **Mentor dashboard**: Manage data access permissions with smart contracts.
- **Role based access control**: Encrypt data before storing it on the blockchain.
- **Login Dashboard**: View and manage your data and permissions.


## Getting Started
1. **Prerequisites**: Node.js, npm, and a blockchain wallet.
2. **Installation**:
   
```bash
   git clone https://github.com/your-username/guardian-link.git
   cd guardian-link
   npm install
   

3. *Usage*:
   npm start
   

Open your browser and navigate to `http://localhost:3000`.
